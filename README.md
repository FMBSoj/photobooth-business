# photobooth-business

## Overview
A responsive landing page for a photobooth service.

## Approach
- Built with semantic HTML and organized CSS.
- Used Flexbox, Grid, and media queries for layout and responsiveness.
- Matched the design’s fonts, colors, and spacing.
- No JavaScript was used since no behavior was specified.

## Tools Used
- HTML5
- CSS3
- Figma
- Visual Studio Code
- GitHub

## Time Spent
Approximately **9 hours**.

## Notes / Assumptions
- Focused on visual accuracy and responsiveness.
- Tested on Chrome and Safari.
